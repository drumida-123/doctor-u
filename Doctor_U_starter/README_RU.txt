# Doctor U — стартовый интерфейс

Это стартовый интерфейс приложения Doctor U на React Native + Expo. Он предназначен для дальнейшей разработки.

## Важно
Этот архив **не является готовым устанавливаемым приложением**. Сейчас в нём есть базовый экран, список предметов и переход в раздел предмета. Загрузка PDF/Word, постоянное хранение файлов, резервное копирование и ИИ пока не подключены.

## Как создать актуальный Expo-проект на Windows

1. Установи Node.js LTS и Visual Studio Code.
2. Открой командную строку (Win + R → `cmd`).
3. Перейди в папку, где хочешь создать проект, например:
   `cd %USERPROFILE%\Documents`
4. Создай новый проект на актуальном шаблоне Expo:
   `npx create-expo-app@latest DoctorU`
5. Когда создание закончится, открой папку `DoctorU` в VS Code.
6. Замени файл `App.js` содержимым файла `App.js` из этого архива.
7. В терминале VS Code запусти:
   `npx expo start`

Если Expo спросит об установке пакетов или обновлении, пришли скриншот, прежде чем подтверждать непонятные действия.

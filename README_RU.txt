DOCTOR_U — версия 1.1 (первый рабочий этап)

Что добавлено:
- Удалён макет ИИ-помощника: приложение остаётся без ИИ и подписок.
- Рабочая навигация: Главная, Мои материалы, Избранное, Профиль.
- Шесть стоматологических предметов.
- Добавление PDF и Word через системный выбор файлов.
- Добавление фотографий и рисунков из медиатеки.
- Копирование выбранных файлов в постоянную папку приложения (Documents/doctor_u).
- Сохранение списка материалов и избранного между запусками.
- Поиск, удаление и просмотр/передача файлов через системное меню.

ВАЖНО:
Это исходный проект для запуска через Expo, а не готовый IPA-файл. Для первой проверки нужен компьютер Windows и iPhone в одной Wi-Fi сети.

ЗАПУСК НА WINDOWS:
1. Установи Node.js LTS: https://nodejs.org/
2. Установи Visual Studio Code: https://code.visualstudio.com/
3. Распакуй ZIP в папку без русских букв, например C:\\DoctorU.
4. Открой папку проекта в VS Code.
5. Открой Terminal -> New Terminal и выполни:
   npm install
6. Затем выполни:
   npx expo start
7. Установи Expo Go на iPhone из App Store.
8. Подключи iPhone и компьютер к одной Wi-Fi сети.
9. Отсканируй QR-код из терминала камерой iPhone и открой ссылку в Expo Go.

ЕСЛИ QR-КОД НЕ ОТКРЫВАЕТСЯ:
- В терминале останови сервер Ctrl+C.
- Запусти: npx expo start --tunnel
- Дождись нового QR-кода и отсканируй его.

ПРОВЕРКА ПЕРВОГО ЭТАПА:
1. Открой любой предмет.
2. Добавь PDF или Word.
3. Добавь фотографию/рисунок.
4. Закрой и снова открой приложение — материалы должны остаться.
5. Проверь поиск, избранное и удаление.

ПРИМЕЧАНИЯ:
- Файлы хранятся локально внутри приложения на устройстве; удаление приложения может удалить эти данные. Резервное копирование ещё предстоит добавить.
- Документы PDF/Word открываются через системное меню «Поделиться/Открыть в…». Встроенный PDF-просмотрщик — следующий этап.
- Раздел «Тесты» пока является заглушкой.
- Expo Go предназначен для разработки и тестирования. Для постоянной установки и публикации iOS понадобится отдельная сборка. Сборку iOS можно запускать через EAS Build в облаке, но для распространения на устройства и App Store действуют требования Apple Developer.
